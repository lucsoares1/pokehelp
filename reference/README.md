# Referência histórica

`mobalytics/` preserva os módulos de conteúdo e renderização usados antes da adaptação para Pokémon. Eles não são importados pelo PokeChess Helper e ficam fora da raiz servida ao navegador. O script de assets desta referência também é histórico; a atualização atual usa `npm run data:import` na raiz.

O visual aprovado continua em `site/styles.css` e `site/compositions.css`. A aplicação ativa usa `site/main.mjs`, `site/lib/` e os snapshots de Pokémon em `site/data/`. Os recursos gráficos originais da base visual e seu manifesto foram preservados em `site/assets/` e `site/assets-manifest.json`.
